# AGENTS.md

This is a coffee shop webapp deployed on Vercel.

## Rules
- Do not change the design unless I ask.
- Keep the coffee shop branding.
- Do not expose API keys.
- Use environment variables for secret keys.
- Make small safe changes.
- Explain what you changed.

## Commands
- Install: npm install
- Run locally: npm run dev
- Build: npm run build

## Deployment
This app is deployed on Vercel through GitHub.
Use a new branch before making changes.
